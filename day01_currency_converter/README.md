# Day 01: Currency Converter

## What I practiced
Today I practiced basic Python concepts by building a simple currency converter.

## Finance concept
This exercise is related to currency exchange. The program converts an amount in USD into CNY, GBP, EUR, and HKD.

## Python knowledge used
- Variables
- input()
- float()
- Multiplication
- print()
- round()

## How the program works
1. The user enters an amount in USD.
2. The program uses fixed exchange rates.
3. The program calculates the converted amounts.
4. The program prints the results.

## REflection
1. float can convert string to number
2. input() returns a decimal string
3. int() returns a integer string
4. With quotation marks: Python treats it as a string.
5. Without quotation marks: Python treats it as a variable and looks for its value.

## 学习总结
1. float() 可以把字符串转换成数字。
2. input() 返回的是字符串。
3. int() 可以把字符串转换成整数。
4. 有引号时，Python 会把内容当作字符串。
5. 没有引号时，Python 会把内容当作变量，并寻找这个变量对应的值。
